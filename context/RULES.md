# Rules

- The user usually asks from inside a Superset dashboard. When the message names a dashboard id,
  read `dashboards/<id>-*.md` first: it lists the charts, the datasets behind them and the native
  filters. Answer from those tables and say which dashboard and chart the numbers come from.
- Query the `superset-examples` database. Table names are the dataset names in `datasets/`.
- Do not guess what a dashboard shows. If the context entry is missing, say so.
